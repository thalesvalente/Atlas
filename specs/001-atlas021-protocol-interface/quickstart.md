# Validação rápida da candidata

Python>=3.11. Em ambiente virtual vazio, construa e instale wheels de packages/protocol
e packages/atlas. Execute exportador ambiental e abra a saída com `atlas serve --source`.
A CLI também oferece inspect e dossier; veja README da candidata para comandos finais.

Verificar: versão explícita, corpus sintético, filtros, comparação com unidades,
timeline/linhagem, erros, dossiê e reconstrução. Desligar/reabrir não muda a fonte.
SDK separado: instalar somente caderno-protocol e executar validação; Atlas/R4 ausentes.
Testes privados integram adaptador real sobre fixtures geradas do Caderno legado.
