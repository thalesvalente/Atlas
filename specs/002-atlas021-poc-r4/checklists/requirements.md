Autoria da especificação: ORQ-A. Data: 2026-10-24.
Caixas avaliam qualidade dos requisitos, não execução ou aceite humano.

- [x] Dez requisitos funcionais são observáveis com critérios claros.
- [x] Escopo segue issue #2 sem domínio/produtor adicional.
- [x] Independência, persistência e reconstrução são definidas.
- [x] Comparação exige tipo/unidade/identidade compatíveis por fonte.
- [x] Ausência, UNKNOWN/HOLD, tempo e perdas são preservados.
- [x] Cenários negativos exigidos estão enumerados.
- [x] Separação público/privado e dono da publicação identificados.
- [x] Sete gates técnicos e PARTIAL/HOLD definidos.
- [x] Gates humanos separados da implementação autorizada.
- [x] Pressupostos, limites e dependências explícitos.
