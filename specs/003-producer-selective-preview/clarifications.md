# Clarificações
- **Quem interpreta o índice de origem?** O produtor privado, nunca o SDK/Atlas público.
- **O que é exportado?** Um recorte de metadados; nenhum payload grande é obrigatório. Ausência e referência não verificada são estados explícitos.
- **Há migração de acervo?** Não. Prévia local ≠ migração histórica nem backup.
- **O viewer precisa de mudança?** Não para o recorte proposto: o modelo Caderno 0.1.0a1 já oferece as entidades relevantes. Se um cenário não couber, registrar finding e solicitar decisão; não alterar o perfil automaticamente.
- **Qual o destino?** Dentro de `.local` do operador, ignorado pelo Git, sem criar outro clone ou worktree.
- **Como lidar com estados ambíguos?** Preservar a literalidade no produtor e mapear conservadoramente; nenhuma revisão científica implícita.
- **Há dados privados no público?** Não: o trabalho público descreve a interface e o contrato; fixtures e mapeamentos sensíveis permanecem no R4 privado.
