# Qualidade da especificação — não é aceite de implementação

- [x] Objetivo e critérios distinguem integração nativa de iframe.
- [x] Fonte/ownership/limites e preservação do original estão explícitos.
- [x] Identidade, precisão, ausência, colisão e não aprovação científica estão especificadas.
- [x] Testes de implementação e comparação no host têm aceites separados.
- [x] Nenhuma pergunta pendente impede a implementação compatível com a constituição.
