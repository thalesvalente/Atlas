# Atlas

Interface genérica para explorar projetos, experimentos, execuções, métricas, evidências e linhagem através de um protocolo interoperável do Caderno Científico.

## Trabalho em curso

ATLAS021 — Frente A, 24/10/2026. Este commit mínimo inicializa o repositório vazio conforme autorização específica da missão. As implementações e decisões de protocolo serão propostas em branches e PRs Draft. A interface não executa experimentos nem autoriza decisões científicas, migração de acervo ou retirada de fontes.

A arquitetura separa produtores, protocolo, armazenamento substituível e interface. Nenhum conteúdo privado foi transferido neste bootstrap. A licença do produto ainda depende de decisão do titular.
